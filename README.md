# dtorh.click

Sitio de **dtorh®**, estudio digital (Barranquilla, Colombia). Publicado con GitHub Pages.

- Las páginas se generan con `python3 build.py` (inicio y `/laboratorio/`).
- Estilos: `assets/dtorh.css` · comportamiento: `assets/dtorh.js` · mapa del inicio: `assets/mapa.js`.
- Publicar = hacer push a `main`. GitHub Pages actualiza el sitio en 1–2 minutos.

Recursos de terceros: Lenis (MIT), Open Peeps (CC0), Inter Tight (OFL).
