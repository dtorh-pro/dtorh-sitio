# cual.click

**Cuál**: comparador gratis de celulares y gadgets. Un producto de **dtorh™** (dtorh.click). No vende equipos.

- Publicado en Cloudflare Pages (proyecto `cual-click`). Publicar = push a `main`.
- Sitio estático de un archivo: `index.html` (datos de equipos en el bloque `EQUIPOS`).
- Categorías: celulares activa; audífonos, relojes, tablets y portátiles marcadas "Pronto".
- Para licenciarlo a una tienda: se cambia marca, catálogo y el WhatsApp del botón final.
